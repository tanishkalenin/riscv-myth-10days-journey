## Step 1: Setting Up Ubuntu in VirtualBox (VMBox)

1. Install **Oracle VirtualBox**
   



2. Install **Ubuntu Linux** inside **Oracle VirtualBox**.




3. Start the Ubuntu virtual machine and open the **Terminal**.
